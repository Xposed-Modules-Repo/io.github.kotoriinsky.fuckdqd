# FuckDQD

**快速去除懂球帝广告及推单相关内容**

</div>

## 功能

**广告**
- 开屏广告：冷启动、热启动开屏
- 信息流 / 列表广告：新闻流、视频、圈子、赛事等列表里的广告
- 弹窗广告：首页插屏弹窗、网页里触发的弹窗
- 横幅 / 详情页广告：赛事页、直播页的广告位，文章转发区下方的广告

**推单 / 博彩**
- 底部「预测」换成「圈子」，比赛页去掉「专业版」与「竞北」
- 比赛详情页去掉「情报 / 专家 / 前瞻」标签

各项功能都能在模块界面单独开关。

## 使用

1. 在 LSPosed 中启用 FuckDQD，作用域勾选「懂球帝」
2. 强制停止懂球帝后重新打开

## 环境要求

- Android 8.0+
- 支持 libxposed API 102 的 LSPosed
- 懂球帝 8.7.2 及以上
